# ConnectHub - Social Media Platform

ConnectHub is a social media web application developed using Python and Django.

## Features

- User Signup and Login
- User Logout
- Create Posts
- Like Posts
- Comment on Posts
- Delete Your Own Posts
- View and Edit User Profile
- Search Posts

## Technologies Used

- Python
- Django 5.2
- HTML
- CSS
- JavaScript
- SQLite

## Setup Instructions

1. Clone or download this repository.
2. Open the project folder in PowerShell.
3. Create and activate a virtual environment.
4. Install Django.
5. Apply database migrations.
6. Start the development server.

### Windows PowerShell Commands

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install django
python manage.py migrate
python manage.py runserver
```

Open this URL in your browser:

http://127.0.0.1:8000/

## Project Objective

The objective of ConnectHub is to demonstrate a social media platform with authentication, posts, likes, comments, profile management, and search functionality.
